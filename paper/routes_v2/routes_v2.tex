\begin{abstract}
This paper reports only receipt-bound finite-set results from a pre-specified
visible-document-date intervention. It is not preregistered, does not estimate
general web leakage, and makes no model-family claim.

\section{Design}
Routes v2 holds post-cutoff content, opaque document identity, question, model,
seed, decoding, and response schema fixed across the two primary arms. Only the
visible document date differs. ExAnte is used solely as a pinned title-year
sampling frame; this study neither reproduces ExAnte nor compares scores with it.
