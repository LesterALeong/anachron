# Submission metadata - deliberately incomplete

This directory is a pre-full-results preview. Do not upload it, request an
endorsement with it, choose arXiv categories, or submit it. The only allowed
state is `preliminary`; the builder rejects final evidence, receipts, GO,
review, and submission inputs.

If a future study is completed and independently reviewed, its metadata must be
created from that future evidence rather than copied from this preview.
