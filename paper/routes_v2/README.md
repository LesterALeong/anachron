# Routes v2 paper scaffold

The final builder accepts only a complete confirmatory analysis root and a clean,
pushed frozen checkout. It replays the sole reducer immediately before TeX and
creates the result fragment and receipts itself. It excludes raw Wikipedia
artifacts, unredacted model records, credentials, and all Routes v1 material.
There is no ready-to-upload PDF or source archive in this directory.

Invoke final-results tooling only as repository-root modules:

```powershell
python -m tools.render_routes_results --help
python -m tools.build_routes_v2_paper --help
```

Direct `python tools/...` invocation is intentionally unsupported.
