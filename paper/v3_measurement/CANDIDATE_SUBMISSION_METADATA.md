# Candidate submission metadata contract

Candidate metadata is generated only from a verified projection and the frozen
candidate manuscript template. This document is not metadata for an upload.
No candidate artifact authorizes outreach, endorsement-code transmission,
arXiv upload, or submission.

The future metadata generator must bind its title, author, abstract,
AI-assistance disclosure, and category selection to a candidate receipt. It
must not copy values from the preliminary preview or expose raw evidence,
terminal answers, authorization records, reviews, or approvals.
