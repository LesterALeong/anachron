# Anachron v3 candidate and local-release acceptance matrix

Schema: `anachron-v3-candidate-acceptance-matrix-v1`

## Pre-outcome revision record

This revision supersedes matrix SHA-256
`01289fcdc79820c815b3de11a068980a71dfb53a0bf3da1f4421235de005af7b`
before any real full-study outcome was generated or read. The former exact
seven-page rule was a presentation constraint rather than a scientific gate and
encouraged sparse, forced page breaks. It is replaced with a compact four-to-six
page research-note target and objective readability checks. No empirical result,
scientific threshold, evidence boundary, or eligibility rule changed.

This matrix governs deterministic projection of a completed full experiment,
candidate-manuscript generation, ten-lens review, and an exact-byte local
release. It does not authorize the full experiment, contact with a researcher,
transmission of an endorsement code, arXiv upload, or submission. The matrix,
candidate contract, result templates, and implementation must be frozen and
reviewed before any outcome-bearing evidence from the authorized real-model
full run is generated or read. Schema-valid synthetic fixtures are permitted
before that freeze only inside isolated, disposable QA roots. They contain no
real-model output, their candidate and release artifacts are never persisted,
and they are never represented or accepted as scientific evidence.

The frozen protocol uses `GO` for two different concepts. This candidate layer
interprets them as follows:

- `full_go.json` is Lester Leong's authority to execute the exact full plan.
- `analysis.json` field `go` is a replay-derived scientific gate status only.
- Every complete, replay-valid, authorized full study is candidate-eligible,
  including a study whose scientific gate is false or whose measured direction
  is zero, below-threshold positive, or negative.
- Local release requires ten approvals of the exact candidate bytes and a
  separate final manuscript approval from Lester. It does not require a true
  scientific gate.
