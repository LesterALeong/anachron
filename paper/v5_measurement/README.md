# Anachron v5 candidate-paper contract

This directory is a static, pre-results paper contract for the v5 successor
measurement. It contains no model output, candidate PDF, local release,
researcher contact, endorsement code, upload, or submission capability.

V5 is a fresh prospective controlled finite-panel measurement. The v4 run is
an excluded operational pilot: `v4_included_count = 0` in v5 evidence,
analysis, metadata, paper results, and source archive. Its custody failure is
disclosed only as design history; no v4 trajectory, raw response, score, rate,
or derived statistic may be used in the v5 paper.

After a separately authorized, complete, custody-valid, replay-valid v5
campaign, the planned local lifecycle is candidate construction, ten
byte-bound internal reviews, a distinct author approval for a local release,
and an explicitly unsent outreach draft. Every stage must consume only the
verified v5 answer-free projection for empirical prose, tables, figures, and
metadata. It must never open terminal answers or raw model prose for paper
content.

The primary panel has eight carried-forward synthetic cases, two modes, two
pinned local models, and two precommitted repetitions: 64 scheduled primary
trajectories. Two opaque compatibility traces are excluded from all metrics.
First-tool non-adherence is a reported trajectory outcome. Conditional
post-cutoff exposure is defined only among first-tool-adherent calls; a model
supplied mismatched date causes no retrieval and is reported as
`date_mismatch`.

The future source archive may contain only `README.md`,
`figures/primary_adherence.tex`, `main.tex`, and `references.bib`. It excludes
raw traces, terminal answers, authorization records, source-audit prose,
reviews, and approvals.

Candidate builds require an explicit absolute `TECTONIC_CACHE_DIR`. The separate
non-hermetic render-smoke CI job provisions a dedicated empty cache from
`https://relay.fullyjustified.net/default_bundle_v33.tar`. The recorded value is
only Tectonic's v33 cache/content identifier, not a verified SHA-256 of that
upstream bundle archive. The cache/content identifier is
`6ffe055852f8faf66c0acbe1a7fb27f87b869a90bad1204f3bf4d9683f597c7c`.
The local builder uses that cache for every `--only-cached` compilation and recompilation. The
builder never falls back to a user or global Tectonic cache.

No asset or future tool in this directory may call Ollama, contact a
researcher, request or transmit an endorsement code, upload to arXiv, or
submit a paper. A local release and an UNSENT draft do not authorize any of
those actions.

Self-custody evidence supports internal consistency and byte replay. It can
detect missing, partial, malformed, or inconsistent artifacts, but does not
provide independent provenance for a coherent rewrite of every locally held
artifact.
