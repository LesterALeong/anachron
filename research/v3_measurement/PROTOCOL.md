# Protocol

The v3 panel contains the original 27 synthetic cases in independent v3
modules plus Equinox Retail. Equinox is valid from 2011-05-06 through
2020-02-14 and is queried as of 2021-06-01. The six v2 falsifier IDs are
disclosed development controls in the full study. The other 22 are primary.

The falsifier uses six outcome-unseen primary IDs. Each scientific trajectory
has exactly two chat requests: a first request with one tool schema and a final
request without `tools`. Before science, exactly two transcript-shaped,
tool-less calibration requests, one per model, must exactly return
`CALIBRATION_OK`; calibration is excluded from all metrics.

GO requires all trajectories valid, the preregistered primary reduction,
no model-negative reduction, and at least one enforced Equinox survivorship
leak for each model. These results are finite-panel descriptions only.

Transport records raw bytes only. Identity requests are bodyless GETs and
chat requests are exact-byte POSTs. Native Ollama 0.33.2 responses are parsed
once with duplicate keys, non-finite numbers, and type aliases rejected.
