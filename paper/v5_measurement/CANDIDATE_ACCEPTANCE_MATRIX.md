# V5 candidate and local-release acceptance matrix

This is an offline pre-results paper contract. It does not authorize a model
call, researcher contact, endorsement-code transmission, arXiv upload, or
submission. Synthetic QA may use only disposable fixture roots with no real
model output and no retained candidate or release artifact.

| Gate | Pass condition |
| --- | --- |
| Protocol identity | Evidence admits only the reviewed annotated v5 tag, exact tag object, peeled commit, source manifest, carry-forward receipt, acceptance matrix, authority contract, materialized plans, and later conditional GO. |
| Carry-forward | All eight v5 registry/card bytes, hashes, and accepted-v4 tag blob IDs match the accepted cards. Any drift stops for a new human audit. |
| Conditional topology | Two opaque excluded compatibility traces run before the primary panel. Only a complete compatibility receipt permits the 64 scheduled primary trajectories. |
| Panel scope | The projection reports eight primary cases, two models, two modes, two repetitions, and 64 scheduled trajectories. Compatibility traces are excluded. |
| V4 exclusion | `v4_included_count = 0` across inventory, replay, projection, paper, metadata, release, and archive. V4 may be disclosed only as an excluded operational pilot that motivated v5 custody and adherence controls. |
| Date isolation | The harness-owned case cutoff alone controls retrieval and scoring. A supplied mismatched date is `date_mismatch`, receives no retrieval, and is reported as a first-tool non-adherence outcome. |
| Taxonomy and continuation | Every first and final response has exactly one predeclared category. First-response non-adherence seals only that trajectory, receives no replacement or retry, and the campaign continues. |
| Generated results | Abstract result text, prose, tables, figure values, captions, and metadata are generated only from the verified answer-free v5 projection. No result field is hand-authored. |
| Reporting | Report first-tool adherence, counts by non-adherence category, conditional post-cutoff exposure among adherent calls with its exact denominator, and eligible paired contrasts only. Repetitions are not independent observations. |
| Outcome neutrality | Any complete replay-valid direction is reportable. Incomplete or operationally invalid campaigns generate no empirical claim. |
| Forbidden claims | No answer-quality, population, live-web, source-authenticity, endorsement, causal-mechanism, or model-ranking claim is permitted. |
| Self-custody limit | Self-custody evidence supports internal consistency and byte replay, not independent raw-response provenance. |
| Archive | The source archive contains only the frozen allowlist, has normalized paths and metadata, recompiles to reviewed PDF bytes, and passes streaming digest, byte cap, and copy/archive round-trip checks. |
| Internal review | Exactly one substantive `APPROVED` report binds unchanged candidate bytes for each of the ten frozen lens IDs. Missing, duplicate, stale, renamed, or publication-raced reports fail. |
| Lester approval | A separate post-review approval binds the candidate receipt, projection, PDF, archive, metadata, disclosure, and review set. It authorizes local release only. |
| Local release and outreach | A create-only local release copies reviewed bytes. A separate renderer may create an explicitly `UNSENT` draft with no recipient or dispatch capability. Neither action authorizes contact, upload, or submission. |
